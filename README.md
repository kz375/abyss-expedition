# TypeBasedGame 2.9.0：敌人骨骼与特效实验室

本更新先进入“美术馆”，不会替换正式战斗中的敌人实现。

## 新增内容

- 新增 Flying、Humanoid、Heavy、Boss 四类敌人骨骼原型。
- 洞窟蝙蝠、暗影刺客、钢铁魔像、深渊领主均复用项目内现有美术，不引入来源不明的新素材。
- 每类敌人支持 Idle、Attack、Special、Hit、Break、Death 六种可测试动作。
- 新增攻击与特殊攻击两套分层特效，并按敌人类型改变颜色、冲击形态与地面反馈。
- 美术馆可显示/隐藏骨骼节点，便于检查重心、关节位置和后续切片绑定。
- 本地导入敌人 PNG 时，模型动作预览同步换图，可直接试验未来的新皮肤。
- 继续优化角色模型渲染稳定性、部件连接与动作预览界面。

## 当前边界

现有敌人图片是合并后的完整 PNG，因此这一阶段使用骨骼驱动整体轮廓的位移、旋转和重量感。真正的逐肢体弯曲需要下一阶段把图片切分或制作网格绑定；当前代码接口已经按可替换结构预留。
