# 实时 Beta 1.4.1：选角与流程修复

日期：2026-09-20。基线为上一份 1.4.0 完整更新包。当前项目没有 Git 元数据，本次使用该完整包对照实际文件。

## 已复现并修复

- 选角弹窗受战斗区域动画的定位上下文影响：390×667 视口内，弹窗原先从 y=186.9 开始、只有 381px 高。将弹窗移至 body 后，完整覆盖视口，内部可滚动，手机横竖屏均可点到最后一个职业。弹窗内增加语言、图鉴和成就入口。
- 开局直接依赖 `crypto.randomUUID()`，接口不可用时抛错。现在优先使用该接口，否则使用随机字节生成本地进度标识；六职业与四档难度的实际点击测试全部通过。
- 浏览器禁止读取存储时，选角直接返回。现在允许开始未保存的远征，显示保存失败提示，可导出备份。若已有可读旧档但无法备份，仍保留旧档并在选角弹窗内明确提示。
- 不兼容存档的错误提示原先位于弹窗下方，不容易看到；现在显示在选角弹窗内，原始备份下载入口保留。
- 恢复存档时关闭残留的图鉴/成就遮罩，并保持暂停状态。
- 存档校验补充结算统计条目、状态布尔值、遗物自有 ID、主怪与召唤物类型，拒绝可能导致后续界面崩溃的损坏数据。
- 持续伤害漏算到期前的最后一小段时间；现在按实际有效时长计算。
- 吸血攻击触发反伤死亡后，敌人仍能被自身治疗复活；现在死亡敌人不再执行吸血治疗。
- 网页资源版本更新为 1.4.1。继续包含此前修复的 Java 静态资源白名单，四个 Beta 脚本均可通过实际 Java 服务加载。

## 更新

使用新的 1.4.1 完整更新包，将包内内容覆盖到仓库根目录，重新构建并重启服务。不要继续上传 1.4.0 旧包。保留服务器 `web-data`、桌面 `saves` 和持久化卷。

本轮不修改 `src/gameBody.java`，正式 Java 游戏版本仍保留 1.2.6。旧版 Beta v1 格式存档不会被强行迁移；不能继续时可下载原始备份。现有 v2 合法存档继续使用。
