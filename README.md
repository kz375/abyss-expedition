# TypeBasedGame 2.9.1：美术馆工作台与敌人动作优化

## 美术馆界面

- 桌面端改为左侧实时舞台、右侧操作台的双栏工作区。
- 页面向下滚动时舞台保持在视口内，可以边看动作边调试。
- 半屏采用吸附式舞台与双列操作台；窄屏自动恢复不遮挡的单栏布局。
- 压缩控制面板间距和按钮尺寸，提高同屏可见信息量。

## 敌人骨骼与动作

- 模型轮廓与骨骼覆盖层现在共用同一条整体运动链，不再各自动作。
- 攻击和特殊攻击改为起势、蓄力、接触、缓冲、回位五段节奏。
- Idle、Hit、Break、Death 增加过渡帧，降低突然位移和机械停顿。
- Flying、Humanoid、Heavy、Boss 使用不同的局部旋转、压缩和伸展语言。
- 动作结束更快、平滑地回到 Idle；Break 与 Death 继续保持最终姿态。

## 敌人特效

- 普通攻击粒子由 12 个降为 6 个，特殊攻击由 18 个降为 10 个。
- 缩小核心闪光、斩击、法阵、地面波、音波和暗影范围。
- 降低整体亮度、辉光、层级和受击位移，确保敌人模型仍是视觉主体。
