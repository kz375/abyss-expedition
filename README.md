# TypeBasedGame 2.10.1：敌人近战重量与场景精修

## 敌人动作

- 地面近战敌人加入后撤压步、双脚踏地、前进攻击、缓冲和分段回位。
- 正式战斗采用独立舞台位移动画，不会再被每帧 UI 渲染清除。
- 普通体近战前进约 124–136px，Heavy/Boss 前进约 92–103px；距离明显但不会贴到玩家身上。
- 脚底加入左右脚印、尘土和接地阴影；Flying 使用空中气流反馈，不显示脚印。

## 敌人特效

- 自身强化从单环 14 粒子升级为双环、18 粒子、中心符文与强化核心光。
- 护盾穹顶扩大并增加内外辉光，治疗、狂暴、反击和召唤使用不同色彩。
- 远程技能仍比角色技能克制，但适度提高亮度、尾迹宽度、移动符文和命中核心的可见度。

## 战斗场景与 UI

- 保持现有左右对战布局，不重排战斗信息。
- 加强道路中轴、石面纵深、落脚阴影和边缘压暗。
- 血条增加内部高光与立体边缘，护盾覆盖逻辑不变。
- 技能按钮增加轻量材质、就绪边缘与悬停反馈。
- Pressure 条和竞技场外框获得更清楚但克制的层次。

## 修复与验证

- 修复敌人近战 class 动画被正式版渲染循环立即清除的问题。
- 61 项规则测试通过。
- 290 项 Web/HTTP 测试通过。
- 180 项真实浏览器测试通过，无运行时异常。
- 3482 项桌面兼容与回归测试通过。
