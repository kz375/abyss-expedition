# TypeBasedGame 2.13.0：全角色骨骼连续性与圣骑士动作包

## 六角色公共骨骼优化

- `humanoid-v1` 增加 15 个关节旋转安全范围，覆盖躯干、头部、双臂和双腿。
- 新增骨骼连续性契约：关节覆盖、根节点混合、脚底落地容差和挂点保持。
- 正式战斗与美术馆使用同一套旋转限制求解，降低极端动作中的关节翻转、断肢、穿模和部件消失。
- 所有角色部件启用稳定背面渲染与透明轮廓，减少转身时整块贴图闪烁。
- Warrior、Mage、Ranger、Paladin、Necromancer、Creator 均共享本轮骨骼优化。

## 可扩展 Action Pack

- 角色加载器由固定的“基础动作 + 公共动作”升级为可叠加任意数量的 `actionPacks`。
- Action Pack 可独立提供上半身姿态、腿部步法和舞台位移，不包含角色图片。
- 未来替换 Skin 时只需重新绑定现有 Humanoid 骨骼，不需要重新制作动作。

## 圣骑士新动作

- `shield_bash`：后脚蹬地、盾面领先的短距离盾击。
- `radiant_charge`：压低重心蓄力后进行长距离圣盾突进。
- `consecration`：单膝下沉、聚集圣光、起身释放的完整施法链。
- `judgment_recover`：审判重击后撤步收剑并恢复胸前防御姿态。
- 正式版圣光挥击、神圣审判、守护祷言和圣光净化已映射到新动作语言。
- 美术馆增加独立圣骑士动作工作台，点击动作会自动切换圣骑士并加载动作包。

- 192 项真实浏览器检查通过，无运行时异常。
- 3482 项桌面兼容、回归与本地化断言通过。
