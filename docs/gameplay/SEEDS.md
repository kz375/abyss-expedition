# 种子与多存档留档

## 使用

运行 `gameBody` 或桌面版。主页始终显示 **2. 读取存档／输入种子（Load save / enter seed）**；不再要求先有当前存档才显示。开始新局也可以选择 **1. Begin expedition**。

在 `Seed >` 输入：

- 一个新的整数，例如 `20260916`：创建新冒险，按该种子初始化随机数。
- 已有种子：读取对应存档，无需重选名字、职业或难度。
- 直接回车：自动生成尚未使用的种子。
- `LIST`：列出保留的种子、角色、楼层、难度和状态；然后输入要恢复的种子。

种子支持整个 Java long 范围（包括 0 和负数）；`00123` 与 `123` 是同一编号。
首页、保存提示、结算页会显示种子。首页 **Continue expedition** 恢复最近活跃冒险。
普通楼层路线菜单选 **5. Leave expedition** 可以退出，保留上一个成功保存的检查点。

## 恢复的具体含义

已有种子是本机对应存档的查找编号，不是把地图重新生成一遍。
恢复最近成功保存的角色名字/职业/难度、等级经验、生命和上限、攻防、金币、药水、护盾、冷却、圣遗物及其加成、复活标记、楼层、战绩、路线访问状态、试炼触发标记，以及随机数生成器的后续状态。

**边界：这是检查点存档，不是每一次键盘输入的录像。** 战斗中途、事件选项中途、奖励选择中途和推格子窗口内的位置/动画不即时保存；关闭后恢复最近成功写盘的检查点。已预留的支线/试炼可能已经消耗。正常完成行动后会更新检查点。
最终 Boss 已击败但奖励还未选择就退出时，保存通关记录，不重新开放 Boss 奖励。

新种子不会删除其他种子的进度。通关/死亡也会保存最终角色及战绩；再次输入该种子显示只读最终记录，不复活、不重打最终战。要开始另一局请使用新种子。

## 文件与兼容

```text
saves/
  expeditions/<种子>.save       每局的权威存档（保留）
  abyss-expedition.save         最近活跃存档的快捷副本
  achievements.properties      所有冒险共享的成就
  session.lock                 进程锁文件；文件存在不代表仍被锁定
```

旧版没有种子的有效单存档，在开始/继续操作时会先分配一个新编号并归档；该编号用于找回旧进度，不声称是旧局最初的随机种子。
旧档迁移失败会停止操作，不删除旧档。损坏的种子存档不会被同编号的新冒险覆盖。
已完成存档拒绝被普通进行中状态覆盖。写入使用同目录临时文件替换；每个种子存档写成功后才更新首页快捷副本。
同时启动两个主游戏使用同一存档目录时，第二个实例会退出，避免互相覆盖。

**数字本身不包含存档内容。** 换电脑时要复制 `saves` 目录；仅输入数字不能从不存在的文件中恢复以前的等级、装备和进度。没有对应存档文件的种子将创建新局。种子不是云同步。
可用 `-Dabyss.saveDir=另一个目录` 切换保存位置，注意不同目录中的存档不共享。
