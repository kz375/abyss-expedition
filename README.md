# TypeBasedGame 2.10.0：正式版敌人骨骼与分级特效

## 正式版敌人模型

- 将美术馆验证过的 Flying、Humanoid、Heavy、Boss 四类模型结构接入正式战斗。
- 21 种正式敌人继续映射到四套可替换外观，不再使用单纯静态图片。
- 每个正式敌人只有一个可见模型层，防止重复图片和重影。
- 新增 Idle、Intent Windup、Attack、Cast、Self Cast、Hit、Break、Death 动作状态。

## 敌人特效分级

- 飞向玩家的远程技能保持略淡，但加入尾迹、五枚移动符文、命中核心、状态粒子和类型颜色。
- 近战攻击保留清晰斩线和接触反馈，不再使用覆盖半个画面的强光。
- 敌人施加在自己身上的屏障、治疗、狂暴、反击和召唤使用更强的核心光、环形符文与护盾穹顶。
- Boss 技能仍比普通敌人更重，但不会盖住角色和 Intent 信息。

## 动作与流程

- Intent 出现时敌人会提前蓄力，执行时根据近战、远程或自身技能切换不同动作。
- 玩家命中敌人时触发 Hit；Break 满触发失衡姿态；死亡动作不会再被迟到的 Hit 覆盖。
- 角色使用药瓶时播放 Channel，击败主敌人时播放 Victory，正式流程实际使用更多已有可替换动作。
- 召唤物攻击只产生自己的战斗反馈，不再错误驱动主敌人的模型。

- 3482 项桌面兼容与回归测试通过。
