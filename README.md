# TypeBasedGame 2.11.0：战斗动作、特效与场景表现升级

## 可替换角色动作

- Humanoid 公共动作由 5 个扩展为 8 个，新增 `combat_ready`、`potion_use`、`recover_step`。
- 三个动作同时包含身体姿态、左右腿步法和舞台位移，可继续复用于所有 Humanoid Skin。
- 正式战斗开场使用独立迎敌架势；药瓶不再复用施法动作，并拥有绿色恢复粒子、核心光和地面环。
- 美术馆加入三个新动作的独立按钮和中英文说明，方便逐项检查和替换。

## 敌人动作与特效

- Flying、Humanoid、Heavy、Boss 使用不同的近战运动曲线：俯冲、敏捷连步、重型踩踏和 Boss 压迫挥击。
- 位移拆成模型身体运动与舞台运动两层，脚步、接地尘土和回位继续独立播放。
- 飞行敌人加入翼流；Heavy/Boss 加强落地尘土；Boss 蓄力增加克制的地面预警圈。
- 自身强化和远程技能保持不同强度，不让敌方特效盖过玩家技能。

## 背景与 UI

- 城堡远景加入保留灯火的漂移雾层、暗部景深和柔和环境辉光。
- 道路补充裂纹、能量余光和前景岩石层次，角色仍站在同一条战斗路面。
- 血条边框、技能角标、Intent 呼吸提示、Pressure 底托和顶部关卡信息统一为暗金属材质。
- 保持左右对战和现有信息结构，不扩大网页面板，不移动核心操作区。
