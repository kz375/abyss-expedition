# TypeBasedGame 2.12.0：职业 Break 融合与敌人技能扩展

## 职业 Break 机制

- 战士：横扫稳定积累 Break；破甲斩打断 Intent 时获得更高破势；处决重斩命中破防敌人后缩短自身冷却。
- 法师：奥术印记继续强化陨星的 Break 与霜环的打断、控制和 Break 效果。
- 游侠：速射标记弱点，双重射击第二箭强化 Break，毒牙箭侵蚀 Break，烟幕可反制正在蓄力的敌人。
- 圣骑士：带盾圣光挥击转化 Break；审判打断获得高 Break；祷言可延长破防窗口；净化会按清除的异常数量转化 Break。
- 死灵法师：诅咒状态使 Break 获取提高 20%；灵魂火和灵魂汲取都能抽取 Break；护甲可延长破防窗口。
- 造物主：现实切割按当前 Break 比例增伤；现实撕裂积累 Break；屏障冻结破防窗口；规则重写清强化并直接重写 Break。

## 敌人攻击与技能

- 新增 `Pounce`：短前摇高速扑袭，考验点按防御。
- 新增 `Bone Barrage`：三段攻击，持续压迫护盾。
- 新增 `Rending Wound`：直接伤害并施加持续裂伤。
- 新增 `Abyssal Fortify`：同时获得护盾和短暂狂暴。
- 新增 `Seismic Crash`：重伤护盾并施加破甲。
- 新增 `Shadowstep`：快速切入并削弱现有护盾。
- 新增 `Hexburst`：玩家身上的异常越多，爆发伤害越高。
- 21 种怪物重新分配为更长、更有体型和定位区别的攻击轮换。

## 表现与反馈

- 七种新敌人动作拥有独立 Intent 名称、前摇类型和远近程分类。
- 堡垒加入金色装甲穹顶；震地、裂伤、暗影步和咒爆使用不同命中特效色彩。
- Break 窗口加强呼吸光提示，但不改变现有战斗 UI 布局。

- 64 项规则测试通过。

- 185 项真实浏览器检查通过，无运行时异常。
